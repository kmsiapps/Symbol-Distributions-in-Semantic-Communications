# Symbol Distributions in Semantic Communications

This repository accompanies the following paper:

H. Yoo, D. Choi, S. Kim, C.-B. Chae, and R. W. Heath Jr., "Symbol Distributions in Semantic Communications: A Source-Channel Equilibrium Perspective," IEEE Transactions on Communications, vol. 74, pp. 13842-13855, 2026.

- IEEE Xplore: https://ieeexplore.ieee.org/abstract/document/11644690/
- DOI: https://doi.org/10.1109/TCOMM.2026.3721631
- arXiv: https://arxiv.org/abs/2512.14022

## Overview

We study the distributions of learned symbols in end-to-end semantic communication systems. The paper develops a source-channel equilibrium perspective and uses a Student's t-distribution to model semantic symbols. Experiments examine how the distribution changes with symbol rate and dataset entropy, and show that distribution regularization can improve training convergence.
